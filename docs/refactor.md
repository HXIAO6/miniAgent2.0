# 模块解耦重构验收

本轮先解决请求配置混用、应用层反向装配依赖、实验替换内部函数三个问题，再拆 API、安全、解析、回收及前端面板。重要新增代码有中文注释。不是安全算法升级，不宣称提高攻击检测率。

## 实际变化

- `bootstrap` 统一装配模型、策略和服务；`RuntimeEnvironment` 隔离请求配置，检索线程继承同一环境。
- `ChatService` 接收内部 `RunCommand`，不再反向导入装配层或读取 HTTP options。
- API 按聊天、会话、文档拆路由；SSE 编码与 HTTP 映射独立，上传暂存交给不依赖 FastAPI 的服务。
- 安全规则、入库检查、上下文过滤与权限策略分开；审计转发移到 observability。
- 解析/分块、Chroma 装配、回收/回滚拆出；保留原 KnowledgeBase 与兼容导出，不改变存储格式。
- 实验核心统一进入 `miniagent.experiments`，原命令是薄入口；矩阵不再用 patch 修改生产函数。模型构造可以注入，检索策略使用共享 collection 的独立实例。
- 来源、设置前端面板独立。`useChat` 共同生命周期暂保留，未强行拆成多个状态 Hook。
- 日志在应用启动时初始化，单纯导入配置不再创建日志文件。

完整目录及调用方向见 [架构说明](architecture.md)。
